# FinAI Analyst

An Agentic RAG Chatbot for Live Stock and Finance Analysis.

## Project Structure
- `data/`: PDF filings and financial reports
- `ingestion/`: Loaders, cleaners, chunkers, and embedders
- `tools/`: Market data tools (`yfinance`) and retrieval
- `agent/`: LangGraph workflow, prompts, guardrails, and memory
- `app/`: Streamlit user interface
- `tests/`: Unit tests
- `evaluation/`: RAGAS scripts and evaluation benchmarks
